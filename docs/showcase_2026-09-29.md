# 三维点云与交互演示扩展

本轮扩充 GitHub README 与 Pages 展示，不修改检测、跟踪算法或既有评估结果。

## 新增内容

- **三维点云查看器：** 城市/高速共 42 个采样时刻；旋转、缩放、斜视/俯视/前视、手动环绕、键盘操作、图层开关与 PNG 下载。相机、框、时间与点云在载入成功后一起切换；较慢的旧请求不能覆盖新选择。
- **分阶段耗时：** 直接读取四份 C++ 对照流水线报告，按检测、相机确认、坐标转换与跟踪、预测绘制均值堆叠条形图。选择阶段查看实测值；总 p95 单列，不把各阶段 p95 相加。
- **匹配演示：** 使用两组 2×2 教学矩阵，调节 IoU 阈值，比较分配前后过滤。第二个示例展示最大有效 IoU 总和不等于最大匹配数量。示例不计入实验精度。
- **视频展区：** KITTI 和 VGGT 既有 GIF 转成 MP4，保留原始帧时序，按播放操作加载；播放新视频时暂停其他视频。
- **README 与入口：** 三维点云封面、两张交互预览和体验导航，支持从仓库首页直达各项演示。

## 数据来源与显示范围

三维点云使用 `docs/assets/replay/{urban,highway}/index.json` 中相同的采样时刻。
从对应原始 NPZ 读取 LiDAR XYZ，核对时间戳与总点数，按原逐帧查看器相同的显示范围
筛选：x ±55 m，y ±45 m，z ∈ [−3, 4] m。用帧 ID 作为随机种子，无放回抽样，
每帧最多 20,000 点。默认显示 12,000 点，另提供 5,000 与 20,000 点选择。

坐标使用小端 int16 XYZ，整数乘以 0.002 得到米，每点六字节，每轴量化误差不超过
1 mm。42 个二进制文件合计约 5 MB，按帧读取，不在首屏一次加载。
各场景 `assets/cloud/*/index.json` 保存坐标约定、点数、原始 NPZ 哈希、二进制哈希和
既有回放 manifest 哈希。颜色按点高度变化，不代表语义类别。

框、轨迹与相机沿用已发布的回放样本，保留 C++ 改动前的跟踪配置。更密的点云仅用于显示，
不重新运行检测，也不改变评估。框仍按评估范围与相机视野筛选。三维视图是已知 XYZ 的
透视投影；环绕功能只改变观察位置，不生成新传感器观测或推进时间。

点云二进制缺失时，使用既有 JSON 的最多 2,500 点并明确显示回退状态。
页面离开可见区域或标签页隐藏时，停止环绕绘制；环绕只在用户点击后开始。

视频转换前后帧数与时长一致：KITTI 314 帧 / 31.4 s，VGGT 40 帧 / 4.8 s。
`assets/gallery.json` 保存 GIF 哈希与转换前后元数据。视频播放时间不代表计算耗时；
KITTI 独立融合报告与展示片段分开说明，VGGT 仍为定性集成展示。

## 复现

在仓库根目录，有原始 CARLA 记录、NumPy、FFmpeg/ffprobe 与 Playwright 时：

```bash
# 输出目录须未使用；先在 outputs 中生成并核对，再替换公开展示资产。
for scene in urban highway; do
  python tools/export_pointcloud.py --dataset "carla/data/$scene" \
    --replay "docs/assets/replay/$scene" --out "outputs/cloud/$scene"
done
python tools/export_gallery.py --out outputs/gallery
python -m http.server 8765 --bind 127.0.0.1 --directory docs
```

另一个终端：

```bash
npm install --prefix /tmp/auto-driver-browser playwright@1.63.0
/tmp/auto-driver-browser/node_modules/.bin/playwright install chromium
export NODE_PATH=/tmp/auto-driver-browser/node_modules
node tools/test_website.cjs
node tools/test_showcase.cjs
node tools/capture_showcase.cjs http://127.0.0.1:8765/ outputs/showcase-previews
```

`capture_showcase.cjs` 使用固定 1440 px 视口、城市第 120 帧、20,000 点与默认教学矩阵，
生成 README 预览。发布站点只需要 HTML/CSS/JavaScript 与这些静态数据，不依赖 CDN。
