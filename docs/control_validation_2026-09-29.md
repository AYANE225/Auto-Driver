# 纵向控制修正与复杂场景验证

本轮修复实际控制中的反复加速、制动和停车后再起步，并重新执行与录制；没有修改旧原始报告，也没有平滑控制记录来改变指标。

## 修正内容

- 正常加速度指令限制在 −3 至 2 m/s²；jerk 限制使用上一条输出指令，避免实测急减速把下一条指令带出硬边界。
- 对计划采用 0.5 秒预瞄，避免反复跟踪重规划的首个采样点而持续加速。
- CARLA 适配器加入速度 PI、阻力和加速度前馈、条件积分、踏板滞回及变化率限制。松油门已有减速能力，低速移动参考允许滑行；紧急制动与终点保持直接生效。
- 终点速度上限按剩余距离衰减。控制每 0.1 秒记录一次，原始实测加速度不截断，规划使用的滤波加速度另保存在车辆状态中。

## CARLA 实测结果

环境为 CARLA 0.9.16、Town10HD_Opt、生成点 6、Tesla Model 3、Python 3.12；独立服务器端口 2100。自车未使用 autopilot。

| 项目 | GT 车道巡航 | 实际 LiDAR 静态障碍 | 实际 LiDAR 前车急刹 |
|---|---:|---:|---:|
| 行驶路线进度 | 70.82 m | 32.62 m | 26.54 m |
| 仿真时长（含末尾停车） | 22.2 s | 18.9 s | 13.7 s |
| 碰撞 / 压线事件 | 0 / 0 | 0 / 0 | 0 / 0 |
| 巡航踏板反向切换 | 0 | 0 | 0 |
| 异常巡航停车 / 停后再起步 | 0 / 0 | 0 / 0 | 0 / 0 |
| 正常加速度指令越界 | 0 | 0 | 0 |
| 全程踏板反向切换 | 1 | 5 | 3 |
| 最小分离轴间隙 | 不适用 | 2.199 m | 0.693 m |

前车急刹测试中，前车实测最高速度为 3.37 m/s，第 6 秒开始全制动。其运动由测试程序控制，自车规划器只获取当时的 LiDAR 检测、跟踪和预测，不读取前车的未来制动安排。
GT 巡航在首次达到目标速度 90% 后、仅统计 `cruise` 状态的速度 RMSE 为 0.102 m/s。

指标由 10 Hz 控制采样计算。踏板大于 2% 视为有效输入；反向切换跨越中间滑行样本也计数。异常巡航停车指车辆曾超过 2 m/s 后，在 `cruise` 状态降到 0.3 m/s 以下；停后再起步指行驶后降到 0.15 m/s 以下，又回升到 0.5 m/s 以上。最后的有意停车不算异常停车。
当前 CARLA 验收还要求正常指令无越界、最高速度不超过目标速度 0.75 m/s、巡航反向切换不超过 2 次、无异常巡航停车和停后再起步。

为核对旧问题，另按统一 5 Hz 采样和 2% 阈值统计“相邻记录直接反向切换”：旧 GT / LiDAR 为 32 / 9 次，新记录降采样后为 0 / 3 次。这个计数与上表跨滑行样本的计数不同。旧、新路线进度和运行时长不同，不据此宣称路线运行效率提升。

## 复杂交互与参数变化

新增三类合成场景：前车先行驶再急刹、邻道车辆平滑切入、绿灯起步后两名行人连续横穿。全部 13 场景分别运行真值检测与合成 LiDAR，共 26/26 次验收通过。

另外执行 18 次单参数变化测试：

| 场景 | 变化参数 | 取值 | 两种输入的结果 |
|---|---|---|---|
| 前车急刹 | 初始前车中心位置（自车后轴起点为 0） | 16 / 20 / 24 m | 6/6 通过 |
| 切入 | 切入持续时间 | 1.5 / 2.5 / 3.5 s | 6/6 通过 |
| 绿灯与行人 | 绿灯时刻 | 8 / 10 / 12 s | 6/6 通过 |

这些运行固定种子 2026，并包含默认参数的重复运行，不能作为独立随机样本估计成功率。
所有测试无实际矩形碰撞、无道路越界、无红灯越线。最小分离轴间隙最低约 0.565 m；它不是欧氏距离或校准安全裕度。
[参数、指标与完整 gzip JSON 记录](assets/driving/interactions/index.json)可逐项复核。

## 展示与检查

- 三段 CARLA 视频均重新录制为 10 Hz，保留原始时序；同步展示实测速度、参考速度、油门、制动和路线进度。点击曲线或用方向键可定位视频。
- 合成回放增加三种场景及事件定位；参数变化表链接完整记录。对比实验保留代码、原报告、视频及相机图像哈希。
- 本地核心测试 142 项通过，3 项因未构建可选 C++ 扩展而跳过；Ruff、回放数值测试和三套浏览器回归检查通过。浏览器检查覆盖 26 份回放、18 份参数报告、三段视频、曲线定位、异步失败与移动布局。
- 已检查相机采样接触表和桌面、手机布局。GT 原始轨迹持续巡航后减速停车，没有显示层伪造的位姿或踏板平滑。

本地原始数据位于 `outputs/longitudinal-driving-{gt,lidar}-final`、`outputs/longitudinal-interactions-final`、`outputs/longitudinal-carla-{gt-final2,lidar-final,lead-final}`。导出产物存于对应的新 `*-web` 目录；公开副本在 `docs/assets/driving/`。

这些是低速、限定道路和指定参数下的验证。合成 LiDAR 无光线遮挡；CARLA 中尚未验证城市路口、真实切入、恶劣天气或多车型标定。前车急刹测试的 0.693 m 最小间隙尤其不能扩展成未知工况下的安全保证。
