What the numbers cover

400 frames per scene; one run per setting. Fusion + IMM, YOLOv8n on RTX 5090; BLAS/OpenMP threads set to 1. Latency excludes five warmup frames, I/O, rendering and evaluation. BEV IoU: MOTA at 0.3, IDF1 at 0.5, HOTA over 19 thresholds. Identical XY region and camera FOV for GT and tracks; occluded GT remains included. Both scenes still exceed the 100 ms sensor interval on average, and recall remains low. These are project evaluations.
